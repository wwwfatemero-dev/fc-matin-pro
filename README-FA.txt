FC Matin PRO — راهنمای انتشار

این پوشه را کامل در ریشه (root) مخزن GitHub قرار بده؛ فایل index.html باید در ریشه باشد.
برای فعال‌سازی: GitHub > مخزن > Settings > Pages > Deploy from a branch > main > /(root) > Save.
پس از انتشار، لینک HTTPS سایت را یک بار با اینترنت باز کن و چند ثانیه صبر کن تا فایل‌های بازی ذخیره شوند؛ سپس می‌توانی حالت پرواز را امتحان کنی.

نصب روی گوشی:
در Chrome اندروید لینک HTTPS منتشرشده را باز کن؛ منوی سه‌نقطه > Install app / افزودن به صفحه اصلی.
دکمه «نصب بازی» نیز در مرورگرهای پشتیبانی‌شده ظاهر می‌شود.

گوگل:
انتشار در GitHub Pages به معنی نمایش فوری در نتایج گوگل نیست. پس از انتشار، لینک سایت را در Google Search Console به‌عنوان URL بررسی و درخواست ایندکس بده. ایندکس‌شدن تضمین‌شده یا فوری نیست.

محدودیت آفلاین:
بازی و فایل‌های اصلی پس از بازدید آنلاین اولیه در حافظه کش می‌شوند. اولین بار برای بارگیری اولیه اینترنت لازم است. صدا و صدای گزارشگر به قابلیت‌های مرورگر و صداهای نصب‌شده روی دستگاه بستگی دارد.
